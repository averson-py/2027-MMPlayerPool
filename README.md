# MM Player Pool Streamlit Prototype

## Local test

1. Install Python 3.11+.
2. Open a terminal in this folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Put the populated workbook in this folder:

`2027 March Madness Player Pool Tracking Skeleton 2026 rnd5.xlsx`

5. Run:

```bash
streamlit run dashboard.py
```

6. Streamlit will open the dashboard at `http://localhost:8501`.

You can also use the sidebar uploader to test the EMPTY workbook or another workbook.

## Next step

This is intentionally a local prototype. Once the layout and calculations are approved, the workbook source can be replaced with a cloud-published data source and the app deployed publicly.
